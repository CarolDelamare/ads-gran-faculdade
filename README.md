# ADS - Gran Faculdade

Repositório destinado ao registro dos meus estudos e exercícios realizados durante a graduação em Análise e Desenvolvimento de Sistemas.

## Organização

Os conteúdos serão organizados por período e disciplina, acompanhando minha revisão das aulas e exercícios.

## Objetivo

Registrar minha evolução em programação, lógica, banco de dados, orientação a objetos, algoritmos e desenvolvimento de software.
